# Teaboom — карточка товара

Тестовое задание для вакансии HTML-верстальщика / Frontend-верстальщика.

Реализована адаптивная карточка товара «Ананасовый улун».

## Реализовано

- HTML5-разметка
- Адаптивная верстка
- Flexbox и CSS Grid
- Адаптация под desktop, tablet и mobile
- Выбор фасовки товара
- Динамическое изменение артикула
- Динамическое изменение текущей и старой цены
- Состояние выбранной фасовки
- Hover и focus-состояния кнопок
- Семантическая HTML-разметка
- Изображение товара

## Запуск

1. Скачать или клонировать репозиторий.
2. Открыть папку проекта в VS Code.
3. Запустить `index.html` через Live Server.
